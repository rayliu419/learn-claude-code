s01 — Agent Loop 基础循环

核心思想：没有循环，就没有 agent。把"模型 + 工具"连接成一个能持续推进任务的主循环。
CC 实现参考 Claude Code 启动函数调用图 — main() 到 SessionStart 完整链路
文件s01_agent_loop.py
关键结构LoopState — messages, turn_count, transition_reason
终止条件response.stop_reason != "tool_use" 时结束
工具仅 bash — 最小演示
def agent_loop(state):
    while True:
        response = client.messages.create(model=MODEL, system=SYSTEM, messages=state.messages, tools=TOOLS)
        state.messages.append({"role": "assistant", "content": response.content})
        if response.stop_reason != "tool_use": return
        results = execute_tool_calls(response.content)  # 执行工具
        state.messages.append({"role": "user", "content": results})
        state.turn_count += 1
  • 关键理解：assistant 回复要写回历史，tool_result 要写回历史，主循环持续推进
  • 初学者常犯：工具结果只打印不写回 messages、不保存 assistant 消息、不给 tool_result 绑定 tool_use_id
  • transition_reason 目前只有 "tool_result"，后续会扩展更多续行原因

# Strategy 2: prompt_too_long → 压缩重试

    messages[:] = auto_compact(messages)

# Strategy 3: 指数退避重试 (connection/rate errors)
