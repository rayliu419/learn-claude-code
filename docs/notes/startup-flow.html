Claude Code 启动函数调用图

启动主链路：main() → SessionStart

main() [src/main.tsx]
├─ Commander CLI 配置
• 注册所有 --flags (--print, --resume, --worktree, ...)
• 注册子命令 (mcp, auth, plugin, skill, task, config)
└─ program.parseAsync() → 触发 action handler
├─ action handler
├─ setup() [src/setup.ts]
├─ Node.js 版本检查
├─ startUdsMessagingServer() — UDS 消息服务
├─ 捕获 teammate/swarm 快照
├─ restoreTerminalSettings()
├─ setCwd()
├─ captureHooksConfig()
├─ startFileWatcher()
└─ 创建 git worktree (可选, --worktree)
├─ 数据库 migrations
├─ 初始化 settings / resolve model / trust dialog
├─ 计算 MCP 配置 / tools / agent definitions
├─ 异步预取 (不阻塞启动)
├─ connectMcpServices()
├─ passEligibilityCheck
├─ growthBookInit
└─ bootstrapPrefetch
├─ processSessionStartHooks('startup')
└─ launchRepl(root, <App><REPL /></App>) [src/replLauncher.tsx]
└─ renderAndRun() — 渲染 Ink 终端 UI
└─ SessionStart — REPL 就绪, 等待用户输入

用户输入处理链

REPL.onSubmit() [src/screens/REPL.tsx]
├─ 检查斜杠命令，直接处理
└─ handlePromptSubmit(text, …) [src/utils/handlePromptSubmit.ts]
├─ processUserInput(text) [src/utils/processUserInput/]
├─ 输入解析, 附件处理
└─ 构建 user message
└─ onQuery(messages, …) → query.ts
└─ query({messages, systemPrompt}) [src/query.ts]
└─ queryLoop() — while(true) 核心循环
├─ 上下文管理 (snip / compact)
├─ callModel() — API 调用 → 流式接收 tool_use + text
├─ handleStopHooks()
├─ 执行 tools
├─ StreamingToolExecutor (流式并行)
└─ runTools() (分阶段执行)
├─ injectAttachments
├─ refreshTools
└─ 有 tool_use? → 继续循环 / return

核心函数说明

main()
src/main.tsx — 入口
配置 Commander.js CLI（flags + 子命令），编排完整启动序列。负责解析 argv、调用 setup()、触发异步预取、执行 hooks、最终 launchRepl()。约 4500 行。
setup()
src/setup.ts — 环境初始化
检测 Node.js 版本、恢复终端设置（iTerm2/Terminal.app）、启动 UDS 消息服务、设置 CWD、捕获 hooks 配置快照、启动文件变更监听、创建 git worktree（可选）。
processSessionStartHooks('startup')
src/hooks/ — SessionStart hooks
启动时异步执行 SessionStart 类型的 hooks。hooks 的返回值（初始消息）作为 initialMessages 传入 REPL。
launchRepl()
src/replLauncher.tsx — REPL 启动器
动态 import <App> + <REPL> Ink 组件，调用 renderAndRun() 渲染到终端。
<REPL>
src/screens/REPL.tsx — 核心交互组件
全屏终端 UI 组件。管理消息列表、用户输入框、会话生命周期。协调 background queue、mailbox、swarm 协调、session persistence。用户 submit 后调用 handlePromptSubmit() → onQuery()。
query() / queryLoop()
src/query.ts — AgentLoop 核心
async generator，每次用户提问触发一次 query()。内层 queryLoop() 是 while(true) 循环：
上下文管理 → callModel() → handleStopHooks() → 执行 tools → injectAttachments → refreshTools → 判断是否继续。一次提问可能多轮 tool interaction。
StreamingToolExecutor
src/services/tools/StreamingToolExecutor.ts — 流式工具执行
流式模式下，在模型输出 tool_use 的同时并行执行工具。读写分离：read-only 工具可并行，write 工具串行。
handlePromptSubmit()
src/utils/handlePromptSubmit.ts — 输入处理入口
执行 UserPromptSubmit hooks、解析附件、构建消息，分发给对应的 handler，最终调用 onQuery()。
